# 002 — 内容领域与小众标准

## 主领域

### 1. 顶级城市景观

- **必须取景中国境内**（含港澳台可标注地区）；禁止默认欧美天际线充数。
- 天际线、滨水、建筑立面须可对应真实城市/地标或可核验机位描述。
- 正文须让读者知道「这是哪」（可指认地点）；图的合法来源写在图片元数据，正文禁止版权说明书腔（见 `authentic-xhs-voice` Skill）。
- 避免：游客扎堆网红机位无新角度、过度滤镜土味、不可追溯的假地点；避免元叙事与直角引号「」。

### 2. 室内设计

- 风格锚点：巴洛克、包豪斯、折衷主义；可扩展至野兽派、日式现代、北欧克制等，需保持审美一致性。
- 偏好：材质、比例、家具与空间关系。
- 避免：廉价软装拼贴、无出处的「豪宅炫耀」文案。

### 3. 电子音乐 / 爵士 / R&B（小众）

- 必须偏小众：非大众耳熟能详的下沉/顶流歌手堆砌。
- 可推荐：地下厂牌、小众制作人、区域场景（club/listening bar）、专辑封面与听觉美学联动。
- 避免：洗脑神曲榜单搬运、侵权音频直传（若平台不允许）。

## 已下线领域

- **地球极地风景（polar）**：整域下线。素材库、检索词、候选生成均不得再出现南极 / 北极科考风光 / 极光冰原等极地题材。

## 小众品味过滤器（必过）

1. **辨识度**：换掉品牌名后，是否仍像「审美编辑精选」而非「大众资讯号」。
2. **熟悉度惩罚**：若主题已是国内信息流高频网红点且无新角度 → 降权或拒收。
3. **可扩展性**：邻近领域（如建筑摄影、听音空间）可入选，但需在候选 `rationale` 写明扩展理由；**不得**借扩展名义重新引入极地/南极。
4. **情感基调**：素材与生成文案须为**正向或平（中性氛围）**；拒收猎奇、惊悚、灾难消融、血腥阴暗等负向情绪主导内容。

## 素材库学习（真实优质帖）

- 在小红书检索「审美积累」以及「城市建筑 / 室内美学 / 小众爵士·电子」等词，采集**真实高互动笔记**的公开元数据写入 `ReferenceMaterial`（见 `001`）：note_id、标题、作者、互动量级、链接、封面/图组公开 URL（若可得）、正文摘要、领域标签、关键词来源。
- **禁止**未授权把他人全文/原图当作账号生成输出；素材库只作标尺与特征对齐，`license_ok` 对第三方默认 false。
- 采集可用官方网页（含已登录浏览器会话）；密钥与 Cookie **不得**写入仓库或提交 `.env`。
- 生成候选的 `taste_score` 须达到同领域真实素材 `quality_score` 的 P75 门槛（见 `001`），否则 `taste_pass=false`，不得视为品味合格。
- **入库门槛**：`domain` 不得为 `polar`；标题/摘要不得含南极等已禁题材；情感须正向或平（见上）；实现见 `material_gates.py`。

## 领域数据源白名单（正式）

权威列表见代码 `apps/api/app/source_registry.py`（`DOMAIN_SOURCES`）。采集与配图必须落在白名单站点（或已登记的授权备援宿主）；**禁止**用无关库存图凑数。

| 领域 | 主站 | 角色 |
|------|------|------|
| cityscape | 小红书、抖音、Instagram 商业摄影 | 选题 + 画面；小红书 = **结构参照 + 正式数据源** |
| interior | 小红书、抖音、设计站（Dezeen / ArchDaily / Designboom / 品牌项目页等） | 同上 |
| music | Bandcamp、Resident Advisor、Discogs、厂牌站（Anjunadeep、Roche Musique、Ed Banger 等）+ 风格关键词检索 | 曲目/厂牌/封面与听感事实必须可核验 |
| board（看板） | Are.na、Pinterest | 跨域视觉板、封面气质与拼贴节奏 |

- 生成候选以 **theme pack**（同主题事实 + 同主题图组）为输入；文案对象必须与图同一检索链。
- Wikimedia Commons 等 **CC 授权宿主**可作为稳定外链备援（须主题匹配）；Unsplash 仅主题严格匹配时可用，禁止通用「夜景/耳机」图。

## 领域检索关键词库（持久）

权威列表见代码常量 `apps/api/app/research_keywords.py`（`RESEARCH_KEYWORDS`）。下次自动/半自动采集应按「领域 → 关键词」遍历，并交叉 `source_registry`。

| 领域 | 关键词（含用户指定 ★） |
|------|------------------------|
| interior | ★折衷主义室内设计；包豪斯室内美学；巴洛克室内设计；野兽派混凝土室内；日式现代室内 |
| cityscape | ★上海浦西内透；重庆夜景天际线；深圳湾天际线；广州珠江新城夜景；香港维多利亚港夜景 |
| music | ★deep house 法国；listening bar 爵士；小众电子厂牌；ambient jazz 黑胶；法式浩室 French House |
| meta | 审美积累；视觉审美板；INS 摄影师 审美 |

扩词原则：视觉/品味强、非纯带货；城市须可指认中国机位；音乐偏小众场景（listening bar / 厂牌 / 曲风）而非热歌搬运；情感正向或平。

3. 再改生成管线配置。
