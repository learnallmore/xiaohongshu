# 003 — 模拟小红书预览 UI

## 目标

运营者在 Web 上看到接近小红书笔记的版式：封面/图组滑动、标题、正文、标签、互动区占位，用于审阅而非复刻官方 App。

## 页面结构

### 今日候选页 `/review`

- 展示当日 3 条候选卡片（缩略封面 + 标题 + 领域标签）。
- 点击进入单帖预览。

### 单帖预览 `/review/[id]`

- **上半**：图组轮播（比例贴近小红书竖图/方图常见比例，可按图元数据适配）。
- **下半**：标题、正文、话题标签、作者头像/昵称占位（配置项）。
- **操作区**：
  - 通过并立即发布
  - 通过并保存草稿
  - 拒绝（可选简短原因）
  - 上一帖 / 下一帖

### 已发布 / 数据页 `/posts`（Phase 2+）

- 列表展示外部笔记 ID、发布时间、最新浏览量、爆款评分。

## 交互原则

- 第一视口聚焦「像不像一条能发的笔记」，不做成仪表盘堆砌。
- 内部字段（`rationale`、`nicheScore`）放在折叠「AI 备注」区，不混进模拟正帖。
- 移动端可用；桌面端居中手机框模拟亦可。

## 视觉

- 不追求像素级抄袭官方 UI；抓住「图文笔记」信息层级即可。
- 避免与现有设计系统冲突（本项目新建，可自定义变量）。

## 验收

- 能一眼判断图组顺序与文案是否可发。
- 操作后状态回写清晰（toast / 状态角标）。
