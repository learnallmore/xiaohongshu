# 000 — 产品愿景与账号定位

## 愿景

打造一个 **小红书生活方式账号运营台**：AI 作为小众品味审美推荐的自动挖掘者，每日产出候选帖，运营者在类小红书预览界面审阅，决定是否立刻发布到真实账号；系统持续采集访问量等指标，据此迭代内容策略与「爆款潜力」判断。

## 账号定位

- **人设**：审美驱动的生活方式账号（非带货硬广号）。
- **调性**：小众、克制、构图与氛围优先；拒绝下沉网红审美与大众耳熟能详的流行符号堆砌。
- **核心领域**（详见 `002-domains.md`）：
  1. 顶级城市景观（天际线、有审美的城市打卡点、建筑构图）
  2. 室内设计（巴洛克、包豪斯、折衷主义等）
  3. 电子音乐 / 爵士 / R&B（偏小众，非下沉歌手）
  4. 地球极地优美风景
- **扩展原则**：可参照小红书上成功的类似审美/生活方式账号，扩展邻近垂直领域，但必须保持「小众品味」过滤器。

## 用户故事（运营者）

1. 每天打开工作台，看到 **3 条** 帖子候选（图组 + 文案 + 标签）。
2. 在模拟小红书界面预览版式与图文组合。
3. 选择通过 / 丢弃；通过时可选择 **立即发布** 或仅存草稿。
4. 已发布帖子由定时任务拉取访问量等数据；系统给出爆款潜力反馈，影响后续选题。

## 非目标（Phase 1–2）

- 不做非官方逆向发帖。
- Phase 1 不实现业务代码，只完成 Spec 与 AI 工作流基建。

## 成功标准（产品级）

- 候选质量稳定通过运营者主观审美关。
- 发布链路合规、可审计。
- 数据回流能解释「为什么这条更像爆款 / 不像」。
