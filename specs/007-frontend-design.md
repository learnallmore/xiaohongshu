# 007 — 前端视觉与交互设计

> 信息架构见 [`003-xhs-preview-ui.md`](003-xhs-preview-ui.md)。本文是 **视觉、版式、动效与组件级** 设计规范；实现以本文为准。

## 产品气质

- **不是**营销落地页，也不是数据仪表盘。
- **是**「审美编辑工作室」：主区沉浸式模拟小红书笔记，侧旁是克制的运营操作。
- 品牌信号：产品名 **「棱镜」**（可配置）；UI 首屏需有可读产品名，勿只剩 nav 小字。
- 用户一打开就该感到：今天有 3 条值得挑剔的候选，而不是一堆 KPI。

## 设计原则（强制）

1. **一个构图**：`/review` 与 `/review/[id]` 第一视口是单一构图，禁止仪表盘式多卡片墙抢视线。
2. **预览即锚点**：模拟手机笔记是主视觉；操作控件从属于预览，不反客为主。
3. **一区一事**：候选列表 / 单帖预览 / 已发布数据 分路由或分明确分区，不在同一视口堆叠统计条。
4. **少卡片**：默认无卡片阴影盒子；仅可交互的候选条目可用轻分隔，禁止 hero 区套卡片。
5. **真实内容优先**：用真实图文占位演示；禁止纯装饰渐变充当主视觉。
6. **克制动效**：2–3 个有意图动效即可（封面淡入、图组滑动、状态切换），禁止闪烁与过度 glow。

## 视觉方向（锁定）

避开：紫白渐变、奶油衬线+陶土、报纸细线密排、默认 Inter/系统字体堆砌、大面积霓虹 glow。

| Token | 值 | 用途 |
|-------|-----|------|
| `--bg` | `#0F1210` | 工作室深底（夜览，利于看图） |
| `--bg-elevated` | `#1A1F1C` | 次级表面 |
| `--ink` | `#E8E4DC` | 主文字 |
| `--ink-muted` | `#9A958A` | 次要文字 |
| `--accent` | `#C4A574` | 点缀（香槟金，少用） |
| `--danger` | `#C45C4A` | 拒绝 |
| `--ok` | `#6B8F71` | 通过/发布 |
| `--phone-frame` | `#2A2E2B` | 手机外框 |
| `--note-bg` | `#FAFAF8` | 笔记内浅底 |
| `--note-ink` | `#1A1A1A` | 笔记内正文 |

**字体**

- UI 壳：`DM Sans` — 几何无衬线，用于产品名与操作。
- 笔记内文：`Noto Serif SC` 标题 + `Noto Sans SC` 正文。
- 经 Google Fonts / 本地 `@font-face` 由 FastAPI 静态资源加载；禁止以 Inter/Roboto/Arial 作为主字体。

## 布局

### 桌面（≥1024px）

```text
┌─────────────────────────────────────────────────────────┐
│ 棱镜          今日 · 3 候选            已发布            │
├────────────────────────────┬────────────────────────────┤
│                            │  AI 备注（可折叠）           │
│     手机框笔记预览          │  领域 / nicheScore          │
│     （主锚点）              │  [通过并发布] [存草稿]      │
│                            │  [拒绝]                     │
│                            │  ← 上一条    下一条 →       │
└────────────────────────────┴────────────────────────────┘
```

- 左：手机框约 390×844 逻辑尺寸，可缩放；图组全宽。
- 右：窄操作柱（≤360px）；按钮微圆角（≤8px），禁止满屏 pill。

### `/review` 今日三条

- 不是三列仪表盘。用横向叙事：一条主预览 + 缩略切换（或显示 1/3、2/3、3/3）。
- 默认第 1 条；切换时预览交叉淡入（200–280ms）。

### 移动（&lt;768px）

- 预览全宽在上，操作粘性底栏在下；顶栏保留产品名。

## 组件级

### PhoneNotePreview

- 顶栏：头像 + 昵称占位。
- 图组横滑 + 圆点指示。
- 标题 / 正文 / 标签层级清晰；标签勿做成彩色 chip 墙。
- **禁止**在图上叠浮动徽章、促销 sticker、统计浮层。

### ReviewActions

- 「通过并立即发布」→ `--ok` 填充。
- 「存草稿」→ 线框。
- 「拒绝」→ `--danger` 文字/线框。

### AiNotes（折叠）

- 默认收起；展开见 `rationale`、`nicheScore`、领域。

## 动效清单（仅这些）

1. 候选切换：`opacity` + 轻微 `translateY(4px)`。
2. 图组跟手横滑 + 吸附。
3. 操作成功短暂 check 态（≤1.2s）。

## 与实现锁定

- 宿主：**FastAPI** 提供页面与静态 CSS（见 `006-tech-stack.md`）；样式为 **纯 CSS + CSS 变量**（不引入 Tailwind 默认组件审美）。
- 路由：对齐 `003`（`/review`、`/review/{id}`、`/posts`）。
- CR 时违反本文「第一视口构图 / 字体色板 / 禁止项」→ 阻塞。

## 验收

- [ ] 去掉顶栏后仍能通过预览区认出「棱镜」审阅，而非通用后台。
- [ ] 第一视口无统计条、无多卡仪表盘。
- [ ] 字体与色板符合本文。
- [ ] 动效不超过上述 3 类。
