# 真实感与去 AI 味（棱镜账号）

综合：账号审美定位、小红书去 AI 味公开实践，以及 [blader/humanizer](https://github.com/blader/humanizer)（基于 Wikipedia「Signs of AI writing」）的检测思路。**去 AI 味 ≠ 堆口头禅**；核心是真实细节 + 可追溯来源（元数据）+ 自然语气。

## 何时使用

- 生成或改写任何候选帖正文/标题
- 用户说「假」「莫名其妙」「AI 味」「行文不对」
- 审阅种子数据、Mock、LLM 输出是否可发

## 硬规则（阻塞级）

### 1. 城市景观 = 中国

- `domain: cityscape` **必须**是中国境内可指认地点（省/市 + 具体片区或地标）。
- 禁止用纽约/迪拜/新加坡等默认「高级天际线」冒充。
- 港澳台须在正文写清地区名，勿含糊成「东方都市」。

### 2. 全领域：真实可追溯 + 图文同源

| 领域 | 最低可追溯要求 |
|------|----------------|
| 城市 | 城市名 + 机位/片区；图来自白名单检索链（小红书/抖音/IG 商业摄影等，元数据可记 Wikimedia CC 备援） |
| 室内 | 风格流派可点名；图对应真实项目/展览/设计站或同主题授权图，禁止假装「我家实拍」 |
| 音乐 | 艺人/厂牌/专辑真实存在且偏小众；图须与该发行/厂牌/现场同源，禁止耳机/演唱会灯库存图 |

**图文同源（阻塞）**：正文写的对象必须就是图里的东西；同一 `theme_key`。数据源白名单见 `specs/002` / `source_registry.py`。

**不做极地/南极**：已下线；勿生成极光冰原科考类题材。情感须正向或平。

缺事实时：**停笔**，标注 `NEED_HUMAN_FACT:`，禁止用漂亮空话填坑。

### 3. 图源：默认进元数据，正文像真人

- 合法来源写在图片字段 `source` / `license`（审阅侧栏可见即可）。
- **正文不要**写说明书腔：`Unsplash License`、`图1–3来源`、`摄影师见原页`、`授权说明` 等。
- 正文若提图，只写与内容相关的介绍（地点、碟名、空间氛围），像普通人发帖。
- **要么不写来源，要么只写内容相关介绍**——不要版权段。

### 4. 禁止元叙事（读者可见正文）

禁止解释自己在做什么运营/学习动作，例如：

- 素材库里某某那批帖只学结构、不搬别人封面
- 参照素材 / 对齐关键词 / 写给审阅看

读者只看笔记，不看你的生成策略。

### 5. 禁止中文直角引号「」

标题与正文**不得出现** `「` `」`。需要强调时改写短句，或不用引号。

### 6. 禁止未授权搬运

不得把他人小红书原图/原文当自己的。学习结构可以，素材必须有权使用；授权信息进元数据。

## 去 AI 味（中文小红书）

### 禁止输出的味道

- **升华腔**：负空间、呼吸感、主灯、生活方式号的安静开场、适合作为…
- **排比三连** / 首先其次最后 / 综上所述
- **营销黑话**：赋能、抓手、闭环、沉浸式体验、绝绝子堆砌、闭眼入
- **假权威**：专家认为、有观察指出（无出处）
- **完美结构**：三段工整、每段都像结尾金句
- **伪口语**：整篇「咱就是说」「谁懂啊」刷屏（比 AI 腔更假）
- **元叙事 / 说明书图源**（见上）

### 应该有的味道

- 像跟熟人发消息：短句、可不对称、可留白
- 一件事、一个细节、一句感受就够；**不要教读者「我为什么这样写」**
- 有「我」的一次具体观察（时间/天气/走哪条路），但**观察必须真实或明确标为待补**
- 防假探店/假实拍：用**极短**口语即可（如「参考图，不是我家」），禁止长篇辩护
- 信息密度高于形容词密度；对标真实高赞帖，而非堆规则口号

### 改写流程（强制）

1. 列出本帖必须保留的**事实清单**（地点、人名、碟名）；图源写入图片元数据。
2. 删掉所有升华句、三连、元叙事、直角引号、版权说明书。
3. 正文只留内容相关句；自问是否像普通人发一条笔记。
4. 自问：换掉城市名/碟名后，句子是否还能成立？若能 → 太空，重写。
5. 跑 `voice_filter` / taste：元叙事、说明书腔、「」、升华腔必须清零。
