# 小红书笔记格式

## 何时使用

- 撰写候选正文与标题
- 校对预览页展示是否「像一条笔记」
- 发布前字段校验（配合 publisher-checklist）

## 规范

- **标题**：短、有画面感；避免夸张承诺与违规词；建议 ≤20 字量级（以平台限制为准）。
- **正文**：分段短句；先氛围后信息；可含轻量地点/风格线索；结尾留白，勿硬广。
- **标签**：3–8 个；中英混用克制；贴合领域，勿堆无关热搜。
- **图组**：3–9 张为宜；第一张即封面，构图最强；顺序讲「节奏」而非随机拼盘。
- **禁止**：未授权搬运原文原图；虚假打卡；侵权音频声称。
