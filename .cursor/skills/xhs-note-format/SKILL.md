# 小红书笔记格式

## 何时使用

- 撰写候选正文与标题
- 校对预览页展示是否「像一条笔记」
- 发布前字段校验（配合 publisher-checklist）

## 规范

- **正文**：以 `.cursor/skills/authentic-xhs-voice/SKILL.md` 为准——地点/图源写给读者看；去 AI 升华腔；短句可留白。
- **标题**：短、有具体地点或对象；避免空审美词堆砌。
- **标签**：3–8 个；含城市名或风格名等可检索实体。
- **图组**：3–9 张；封面最强；顺序有节奏。
- **禁止**：未授权搬运；虚假打卡；正文不交代图源；城市帖用境外冒充。
